# 사이트 설계도(PRD) — 초보용 반려식물 가게 (사이트 이름 미정)

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
식물을 처음 키우는 사람을 위해, 키우기 쉬운 실내식물을 골라 집으로 보내 주는 곳.

## 2. 손님
- 누가: 식물을 처음 키우는 1인 가구 (원룸·자취방을 꾸미고 싶지만 식물을 죽일까 걱정하는 사람)
- 어디서 알고 오나: 인스타그램 (프로필 링크를 눌러서 들어옴 → 휴대폰 화면 기준으로 만든다)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 정말 안 죽나요? — 키우기 난이도, 물 주기·햇빛 같은 관리 방법
2. 가격과 배송비
3. 배송 중에 상하면 어떻게 되나요? — 포장과 교환 안내

## 4. 믿게 할 증거 (실제로 있는 것만)
- 지금은 없음. 실제 식물 사진이 생기면 넣는다. (사진 자리만 만들어 둠)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 내 방에 맞는 식물 추천받기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로, 한 페이지)
1. 첫 화면 — 한 문장 + 버튼 "내 방에 맞는 식물 추천받기"
2. 초보도 안 죽게 — 키우기 쉬운 이유와 기본 관리법(물·햇빛) 짧게
3. 가격·배송·교환 안내 — 8번 사실 그대로
4. 후기 자리 (비워 둠)
5. 문의 폼 (추천 요청)

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 방에 드는 햇빛 정도 (예: 잘 듦 / 조금 듦 / 거의 안 듦)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 1만원
- 배송비: 4,000원
- 교환: 도착 후 당일 사진 보내주시면 교환
- 시간: (미정)
- 위치: (미정 — 온라인 배송)
- 연락 방법: 010-0000-0000 · 인스타그램 아이디 (미정)

## 9. 이번에 넣지 않을 것
- 온라인 결제 (장바구니·카드 결제)
- 회원가입·로그인
- 상품별 상세 페이지
- 사진 올리기, 알림 메일

## 10. 첫 화면 한 문장 후보
1. 식물 처음이세요? 안 죽는 식물부터 골라 드릴게요.
2. 내 방 햇빛에 맞는 식물, 대신 골라 드려요.
3. 자취방에 초록 하나, 초보도 괜찮아요.

## 11. 다음에 할 것
- 실제 식물 사진 찍어서 넣기
- 실제 후기가 생기면 후기 자리에 넣기
- 인스타그램 아이디 정해서 넣기, 사이트 이름 정하기
- 온라인 결제 붙이기 (주문이 늘어나면)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
